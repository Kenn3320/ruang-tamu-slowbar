# Ruang Tamu Slow Bar Roastery — Website Concept

A website concept for **Ruang Tamu Slow Bar Roastery**, a coffee shop in Batam, Indonesia.

This project explores how a dedicated website can help a local coffee shop showcase its menu, introduce its atmosphere, and make its location easier for customers to find.

## Features

- **Brand-focused design** — A visual identity inspired by the shop's black, cream, and orange branding.
- **Menu showcase** — Coffee, non-coffee beverages, and food menu categories with prices.
- **Storefront gallery** — Visual references to the shop and its coffee preparation.
- **Google Maps integration** — An embedded map and directions link to help visitors locate the shop.
- **Contact and social links** — Quick access to the shop's contact information and Instagram.
- **Responsive layout** — Designed to adapt to desktop and mobile screens.

## Tech Stack

- HTML
- CSS
- JavaScript
- Google Maps Embed

## Project Status

This is an independent portfolio concept created to demonstrate web development and website design skills.

It is not an official website and is not affiliated with or endorsed by Ruang Tamu Slow Bar Roastery.

Business information, menu details, prices, operating hours, and imagery should be verified with the business owner before any official use.

## Purpose

The goal of this project is to explore how a simple, well-designed website can improve a local business's online presence and help potential customers discover its offerings and location.
